# В Точку

Онлайн-карточная игра на 2–6 игроков: заяви, сколько взяток возьмёшь, и попади в точку. Комнаты по коду, пустые места занимают боты, таймер хода, режим обмана с проверками.

## Структура

```
engine/engine.js   — правила игры и боты (без графики и сети; переносится на любой движок)
server/server.js   — сервер на Node.js: комнаты, ходы, боты
server/db.js       — игроки, сессии, рейтинг: Postgres (Neon) по DATABASE_URL, без него — в памяти
server/rating.js   — попарное Эло (старт 1000, K=32, ушедший — последний)
server/google.js   — проверка входа через Google (ID-токен) без внешних библиотек
client/            — веб-клиент (чёрное с золотом, 2.5D): меню, лобби с QR-кодом, стол, кресла, анимации
  cards.js         — колоды, нарисованные кодом (SVG): чёрная с золотом; cards-sil.js — «Силуэты» (по умолчанию); cards-light.js — классика
  i18n.js          — языки интерфейса (русский, английский): переводы, журнал и ошибки сервера
  brand.js         — логотип «аноним в капюшоне»; icons/ — иконки приложения
  viewport.js      — масштабирование: виртуальный экран высотой 488, вписанный в любой экран через CSS zoom
  voice.js         — голосовой чат «нажми и говори» (WebRTC, звук напрямую между телефонами)
  sw.js, manifest  — установка игры как приложения (PWA)
  music.js         — фоновая музыка: меню, рейтинговое лобби, победа (громкость 10% по умолчанию, регулятор и выключатель в «Звук» ♪)
  music/           — треки mp3 (громкость выровнена, 128 кбит/с)
  fx.js            — эффекты по мастям (♠ сталь, ♣ изумруд, ♦ лёд, ♥ пламя, 7♠ гроза) и синтез звука
prototype/         — первый офлайн-прототип против ботов (один HTML-файл)
test-engine.js     — проверки правил: масть, 7♠, 2–6 игроков, режим обмана, партии ботов
test-online.js     — проверка: создаёт комнату, двое игроков и боты играют партию до конца
test-rating.js     — проверки рейтинга, входа через Google и партии с аккаунтами
test-lobby.js      — открытые столы, подбор игроков (рейтинг на 4, трое + бот), автостарт
test-away.js       — вылет игрока: бот ходит за него, 2 минуты на возврат, голосование после 20 с
test-modes.js      — тестовый режим: «Бескозырка», «Тёмная», окно пересдачи
client/tutorial.js — обучение: партия с 4 ботами прямо в браузере (без сервера), сценарий раундов 1–5, подсветка и подсказки
test-tutorial.js   — проверка сценария обучения: каждая подсказка срабатывает, очки сходятся
scripts/build-static.js — сборка клиента для статического хостинга (папка dist/)
```

## Обучение и экран загрузки

Новичок видит окно «Добро пожаловать в игру «В Точку»» со входом через Google и кнопками «Пройти обучение» / «Пропустить».
Обучение — партия 1-2-3-4-3-2-1 с 4 ботами без таймера: раунды 1–5 подтасованы (старшая карта, козырь, 7♠, очки, обман),
нажать можно только подсвеченное; 6–7 — сам, в режиме обмана. Отметка о прохождении хранится в аккаунте Google
(без входа окно появится снова; кто уже играл на рейтинг — обучение не предлагается). Пройти заново — «Правила» → «Пройти обучение».

Пока сервер Render просыпается, игра показывает свой экран загрузки, и обучение можно пройти прямо во время ожидания.
Чтобы заставка Render не появлялась даже при самом первом входе, клиент можно выложить на **Render Static Site** (он не засыпает):
New → Static Site → тот же репозиторий, Build Command `npm run build:static`, Publish Directory `dist`. Сейчас он работает по адресу https://pousham-1.onrender.com.
Клиент с другого адреса сам обращается к API на `https://pousham.onrender.com`. Адрес статического сайта нужно добавить
в Google Cloud → OAuth Client → Authorized JavaScript origins.

## Запуск у себя

Нужен Node.js 18 или новее.

```
npm start
```

Откройте http://localhost:3000. Проверки: `npm test`.

## Выкладка на Render

1. На Render: **New → Web Service** → подключить GitHub → выбрать репозиторий `PoUsham`.
2. Настройки:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
3. **Deploy Web Service.** Через пару минут игра будет по адресу вида `https://pousham.onrender.com`.

Бесплатный сервер засыпает после простоя: первое открытие может занять около минуты. Комнаты хранятся в памяти и пропадают при перезапуске сервера.

## Как сервер и клиент общаются

Клиент отправляет действия `POST /api/action` (`bid`, `play`, `nextRound`, `start`, `restart`) и получает состояние стола через поток `GET /api/events` (Server-Sent Events). Каждый игрок видит только свои карты. Новый клиент (мобильный, Godot, Unity) должен реализовать только этот обмен — сервер и правила не меняются.

## Рейтинг и вход через Google

Переменные окружения на Render:

- `DATABASE_URL` — строка подключения Neon (Connect → pooled). Таблицы создаются сами при запуске.
- `GOOGLE_CLIENT_ID` — Client ID из Google Auth Platform (тип Web application, origin `https://pousham.onrender.com`).

Проверка: `https://pousham.onrender.com/health` — `db: "ok"` и `google: true`.
Главный экран: слева логотип и «Spot On», справа плашка игрока и разделы **Рейтинговая игра** / **Обычная игра** / **Создание лобби**, внизу Настройки · Правила · Полный экран.
Режимы: **Рейтинг** — только стол на 4, подбор соперников близкого рейтинга (вход через Google); за минуту не набрались — трое + бот; первые 5 партий — калибровка;
**Обычная** — быстрый подбор игроков, список открытых столов, вход по коду, игра с ботами; **Создание лобби** — по коду (приватный) или открытый (в списке). В рейтинг идут только рейтинговые столы;
в таблицу лидеров — после 5 партий.

**Тестовый режим** (настройка своего стола): 17 раундов, 10-й — «Бескозырка» (червы не козырь), 15-й — «Тёмная» (заявка вслепую, очки ×2).
**Пересдача** — в окне 5 с после раздачи, до заявок.
**Двойные очки** — первый и последний раунд партии: все очки ×2 (с «Тёмной» ×4). Точный ноль — 5 + 1 за карту. Ошибочная проверка: проверявшему −20, проверенному +5.
